## 1. プロジェクト概要

### 1.1 背景

AWS を利用する開発者・運用者は、複数の AWS アカウントやロールを日常的に切り替える必要がある。既存ツール（awsume, aws-vault 等）は機能的だが、以下の課題がある：

- **起動速度**: Python ベースのツールは起動に 200ms 以上かかる
- **UX**: プロファイル選択がコマンドライン引数のみで、インタラクティブな選択機能がない
- **履歴管理**: 頻繁に使うプロファイルを素早くアクセスする機能がない

### 1.2 目的

Rust で実装された高速・モダン UX の AWS プロファイル切り替えツールを提供する。

### 1.3 ターゲットユーザー

- AWS を日常的に利用する開発者
- 複数の AWS アカウント/ロールを管理する SRE・DevOps エンジニア
- CLI ツールを好むパワーユーザー

## 4. 制約事項

### 4.1 技術的制約

- **言語**: Rust (edition 2021)
- **最小 Rust バージョン**: 1.75
- **非同期ランタイム**: Tokio
- **AWS SDK**: aws-sdk-rust

### 4.2 運用上の制約

- AWS STS API のレート制限に従う
- IAM ロールのセッション時間制限 (最大 12 時間)
- MFA トークンの有効期限 (30 秒)

---

## 5. 用語定義

| 用語 | 定義 |
|------|------|
| プロファイル | `~/.aws/config` または `~/.aws/credentials` に定義された設定セクション |
| AssumeRole | AWS STS API を使用して一時的なクレデンシャルを取得する操作 |
| ロールチェーン | あるロールから別のロールを順次引き受けること |
| MFA | Multi-Factor Authentication（多要素認証） |
| セッショントークン | 一時的なクレデンシャルの一部 |
